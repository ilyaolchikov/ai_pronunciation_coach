# Intentional-error recordings

Record the six files named in `../manifest.v1.json`. Use the same microphone, distance,
room, and natural speaking pace for every file. Read `spoken_text` exactly, including the
intentional replacement in each substitution case.

Recordings are local development data and are ignored by Git. WAV mono at 44.1 kHz or
48 kHz is recommended, but the normal bounded audio loader also accepts other supported
formats and sample rates.
